# Шаг 06. Catalog filter counters

## Цель

Реализовать счетчики фильтров, которые считаются по той же публичной базе товаров, что и выдача каталога.

## Зависимости

- Product query builder из шага 03.
- Category tree/path resolver из шага 02.

## Файлы

- Создать: `app/Domain/Catalog/Actions/BuildCatalogFiltersAction.php`.
- Использовать в: `BuildCatalogPageAction`.

## Задачи

1. Реализовать расчет регионов:
   - учитывать категорию, поиск, доступность и состояние;
   - исключить активный `region`;
   - считать `count(distinct products.id)`;
   - вернуть справочник `regions` с count и href.
2. Реализовать расчет категорий:
   - учитывать активные фильтры, кроме текущего category filter;
   - посчитать прямые counts по `products.category_id`;
   - прокатить counts вверх по дереву;
   - вернуть дерево с `children`, `level`, `href`, `count`.
3. Реализовать расчет доступности:
   - источник: `equipment_availabilities`;
   - учитывать категорию, поиск, регион и состояние;
   - исключить активную `availability`;
   - вернуть count и href.
4. Реализовать расчет состояния:
   - источник: `equipment_states`;
   - учитывать категорию, поиск, регион и доступность;
   - исключить активный `state`;
   - вернуть count и href.
5. Для всех href:
   - сохранять остальные активные фильтры;
   - сбрасывать `page`;
   - не добавлять пустые/default query params.

## Важные правила

- Счетчики не должны включать товары без `published_at`.
- Счетчики не должны включать товары не в статусе `В продаже`.
- Для many-to-many регионов всегда нужен `distinct products.id`.
- Активный фильтр своего типа исключается при расчете счетчиков этого типа.

## Проверка

- Региональные счетчики не дублируют товар, если у него несколько регионов.
- Category count включает товары дочерних категорий.
- Справочники возвращаются динамически из БД, а не из констант.
- Ссылки фильтров сохраняют активный search/sort/другие фильтры.

## Готово, когда

- API `/api/catalog/page` может вернуть полный блок `filters`.
- Логика счетчиков не расходится с логикой выдачи товаров.
