# Шаг 02. Category tree and path resolver

## Цель

Создать сервис, который строит пути категорий, ссылки, breadcrumbs и умеет находить категорию по полному `category_path`.

## Зависимости

- Модель `Category`.
- Структура категорий: `id`, `name`, `slug`, `parent_id`, `title`, `description`, `og_image`.

## Файлы

- Создать: `app/Domain/Catalog/Support/CategoryTreeBuilder.php`.
- Создать при необходимости: `app/Domain/Catalog/Actions/ResolveCatalogCategoryPathAction.php`.

## Задачи

1. Загрузить все категории одним запросом.
2. Отсортировать категории по `name` или `id`, если в проекте нет `sort_order`.
3. Построить дерево `parent_id -> children`.
4. Для каждой категории вычислить:
   - `path`: массив slug от корня до текущей категории;
   - `pathString`: строка вида `tokarnye-stanki/16k20-i-analogi`;
   - `href`: `/catalog/{pathString}`;
   - `level`: глубина в дереве;
   - `breadcrumbs`: цепочка родителей.
5. Реализовать поиск категории по полному path:
   - `null` или пустой path означает общий каталог, категория `null`;
   - несуществующий path возвращает `null` или доменное исключение, которое controller преобразует в `404`.
6. Реализовать получение descendants ids:
   - в список входит id текущей категории;
   - включаются все дочерние категории любой глубины.
7. Подготовить метод для возврата дерева категорий с полями, нужными API-фильтру.

## Важные правила

- Нельзя искать категорию только по последнему slug: slug может быть уникальным сейчас, но URL описан как полный path.
- `href` всегда строится из полного пути от корня.
- Для первого этапа можно собирать потомков в PHP, потому что в БД 63 категории.

## Проверка

- Для корневой категории `path` содержит один slug.
- Для дочерней категории `path` содержит всю цепочку slug.
- `href` начинается с `/catalog`.
- Descendants ids включают текущую категорию.
- Несуществующий path обрабатывается как `404` на уровне API.

## Готово, когда

- Есть единая точка построения category path.
- Ее можно использовать и в API списка, и в API категории, и в canonical href товара.
